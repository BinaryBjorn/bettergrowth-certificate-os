# specs/

Het plan- en spec-huis van je skills. Twee soorten bestanden:

- **`skill-plan.md`** — het master-overzicht: alle skills die je wil bouwen, geprioriteerd, met hun soort en status (`gepland` → `gespecced` → `gebouwd` → `getest`). Gemaakt en bijgehouden door `/understand-me-better`.
- **`spec-<naam>.md`** — één spec per skill: soort, doel, input, context, de stappen of de regels, output, opslagplek, testcriteria. Geschreven vóór de skill gebouwd wordt.

Twee soorten skills:

- **Werkwijze-skill**: een vast proces, stap voor stap. Claude volgt jouw route. Bv. de maandelijkse concurrentie-scan.
- **Kennis-skill**: spelregels en een kwaliteitslat. Claude kiest zelf de route, binnen jouw regels. Bv. je tone of voice.

De test: is het een stappenplan, of "let hierop"? De meeste skills zijn een mix; `/understand-me-better` helpt je kiezen.

De werklus: plan op papier → `/understand-me-better` → `skill-plan.md` → per skill opnieuw grillen → `spec-<naam>.md` → bouwen → testen in een verse chat → `/bewaar-op-github`.
