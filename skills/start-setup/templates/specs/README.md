# specs/

Het plan- en spec-huis van je skills. Twee soorten bestanden:

- **`skill-plan.md`** — het master-overzicht: alle skills die je wil bouwen, geprioriteerd, met status (`gepland` → `gespecced` → `gebouwd` → `getest`). Gemaakt en bijgehouden door `/understand-me-better`.
- **`spec-<naam>.md`** — één spec per skill: doel, input, context, acties, output, opslagplek, testcriteria. Geschreven vóór de skill gebouwd wordt.

De werklus: plan op papier → `/understand-me-better` → `skill-plan.md` → per skill opnieuw grillen → `spec-<naam>.md` → bouwen → testen in een verse chat → `/bewaar-op-github`.
