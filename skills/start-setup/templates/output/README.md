# output/

Gegenereerde deliverables: campagnebriefs, salesscripts, landingsteksten, advertentievarianten, memo's.

- Elk bestand opent met één zin: *"Gegenereerd op <datum> op basis van <de gebruikte context/-docs>."*
- Outputs verwijzen naar `context/`, ze dupliceren nooit.
- Een output is een snapshot: hij mag verouderen, de context is de waarheid.
